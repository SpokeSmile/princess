# Бюро писем

Личный детективный квест для Ксюши. Чистые HTML, CSS и JavaScript, без внешних сервисов, запросов к ИИ и платных зависимостей.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Открой http://localhost:4173. После правок обновляй страницу браузера. Если порт занят: `npm run dev -- --port 4174`.

```sh
npm run check
npm run build
```

Готовый статический сайт находится в `dist/`. Эту папку можно разместить на любом хостинге статических сайтов. Локальный сервер предназначен для просмотра на своём компьютере.

## Где менять

- `src/content.js` — имена, личное письмо, приглашение, тексты загадок, ответы и подсказки.
- `src/styles.css` — цвета, типографика, анимации и оформление для телефона.
- `src/app.js` — экраны, действия и переходы.
- `src/game.js` — проверка ответов и восстановление прохождения.

В тексте письма можно использовать `{reply}`, `{nickname}`, `{recipient}` и `{author}` — они подставляются из личных полей в начале файла.

После правок открой меню «Начать заново» на главной или увеличь `storyVersion` в `src/content.js`. Личные фразы в третьем задании и ответ в четвёртом тоже находятся в этом файле.

## Сценарий и ответы

1. Три конверта: верно ровно одно утверждение. Письмо в **бордовом**.
2. Первые буквы пяти строк дают **ИСКРА**.
3. Порядок четырёх фрагментов: **a → b → c → d**. Содержит вашу фразу «И я тебя люблю».
4. Обращение **Принцесса**; принимаются также Ксюша и Ксения.
5. Письмо от Максима и приглашение на прогулку. Дата и маршрут пока не назначены.

Прогресс хранится только в браузере посетителя. Кнопка «Пойдём гулять» показывает ответ на экране и ничего не отправляет Максиму. У каждой загадки три подсказки; после третьей можно открыть ответ и пройти дальше. Фрагменты двигаются кнопками, включая управление с клавиатуры.

## Перед отправкой

Прочитай финальное письмо и поправь его своим голосом. Назначь время и место прогулки, если хочешь конкретное приглашение. Открой весь квест на её предполагаемом устройстве и убедись, что сохранение сброшено.

В статическом сайте ответы и письмо доступны в загружаемых файлах: это сценарный сюрприз, а не защищённый сейф. Не добавляй туда секреты, интимные данные и приватные переписки. Если понадобится свободный разговор с настоящим ИИ или отправка ответа, потребуется серверная часть; ключи нельзя хранить в браузерном коде.
