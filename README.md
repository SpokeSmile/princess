# Тихоречье · 1996

Мистическое расследование в вымышленном городе. На главной — бесплатное дело и три карточки платных расследований; карточки предлагают сначала пройти бесплатное. Платежей и реализации других дел пока нет.

Фронтенд: HTML, CSS и обычный JavaScript без npm-зависимостей. Сервер: Django + SQLite, разговор через Mistral API. Личность отправителя и ответы проверяются только на сервере.

## Запуск

Первичная подготовка Python и установка зависимостей описаны в [backend/README.md](backend/README.md). После неё:

```sh
npm run dev
```

Откройте http://localhost:4173. Другой порт: `npm run dev -- --port 4174`. Команда применяет миграции и запускает Django с фронтендом и API на одном адресе.

Скопируйте `backend/.env.example` в `backend/.env`, впишите `MISTRAL_API_KEY` и перезапустите сервер. Ключ никогда не попадает в клиентские файлы. Пока ключа нет, документы, вопрос по фильму и проверка разгадки работают; свободный разговор честно сообщает, что связь не настроена.

Для работы без оплаты используйте ключ аккаунта Mistral в Free mode и модель, доступную в его бесплатной квоте. Доступность и ограничения зависят от аккаунта провайдера. Автоматического перехода на платную модель нет.

## Сценарий

1. Игрок открывает нейтральное письмо без адреса и изучает архивные материалы.
2. После письма и ещё одной улики на линии появляется сюжетный вопрос: фильм «До встречи с тобой», 01:02:43–01:03:30. Ответ можно вписать в карточку фрагмента или отправить в чат. Он проверяется сервером.
3. После проверки фрагмента открывается возможность назвать отправителя, опираясь на шифр и запись дежурного.
4. Верная версия закрывает дело нейтральным подтверждением. Личного признания и следующего этапа сейчас нет.

Фиксированные сюжетные реплики управляют этапами; свободные вопросы отправляются настоящему Mistral. Сервер передаёт ему только найденные материалы, без готовой личности и ответа на вопрос по фильму. История и прогресс хранятся на сервере в сессии браузера; блокнот — локально. Сброс дела очищает сюжетный прогресс, но не квоту разговоров этой сессии.

## Где менять

- `src/content.js` — публичные документы, карточки и фильм с таймкодом.
- `src/styles.css` — ночной город, типографика, карточки, адаптация к телефону.
- `src/app.js` — экраны, модальные окна, переписка и формы.
- `backend/quest/story.py` — приватная проверка ответов и ограничения персонажа.
- `backend/quest/views.py` — серверные переходы и обращения к Mistral.
- `backend/.env` — ваш ключ и параметры сервера; файл исключён из Git.

## Проверка и размещение

```sh
npm run check
npm run build
backend/.venv/bin/python backend/manage.py test quest
```

`dist/` содержит только статическое оформление. Для работающего чата, сохранения и проверки ответов нужен Django. На своём сервере используйте Gunicorn + Nginx; примеры и настройка HTTPS — в `backend/README.md` и `backend/deploy/`.
