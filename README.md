# Тихоречье — Письмо без даты

Мистическое расследование в вымышленном городе. На главной — бесплатное дело и карточки других расследований; карточки предлагают сначала пройти бесплатное. Платежей и реализации других дел пока нет.

Фронтенд: HTML, CSS и обычный JavaScript без npm-зависимостей. Сервер: Django, SQLite локально или PostgreSQL на Vercel; разговор через Groq API. Проверки ответов и открытие личного письма происходят только на сервере.

## Запуск

Первичная подготовка Python и установка зависимостей описаны в [backend/README.md](backend/README.md). После неё:

```sh
npm run dev
```

Откройте http://localhost:4173. Другой порт: `npm run dev -- --port 4174`. Команда применяет миграции и запускает Django с фронтендом и API на одном адресе.

Скопируйте `backend/.env.example` в `backend/.env`, впишите `GROQ_API_KEY` и перезапустите сервер. Ключ никогда не попадает в клиентские файлы. Пока ключа нет, документы, вопрос по фильму и проверка разгадки работают; свободный разговор честно сообщает, что связь не настроена.

Для работы без оплаты используйте Free tier Groq и доступную в его квоте модель. По умолчанию выбрана `qwen/qwen3.8-27b` без режима рассуждений. Доступность и ограничения зависят от аккаунта провайдера. Автоматического перехода на платную модель нет.

## Сценарий

Дело занимает ориентировочно 20–30 минут. Игрок восстанавливает дату по записи дежурного, кинофрагменту, повреждённому оттиску и отметкам на обороте конверта.

Шесть строк записки сначала дают месяц по первым буквам. После ответа о предмете из фильма открывается оттиск с шаблонами: полосатый узор показывает число и пометку «СТРОКА. СЛОВО.». Игрок возвращается к той же записке и читает слова по парам с конверта. Нумерацию строк и слов можно включить для удобства; переносы текста на телефоне не меняют координаты. Новых документов для года нет.

Проверка года работает на сервере и принимает запись цифрами или словами. Найденный год сохраняется, но не открывает письмо сам по себе: полная дата проверяется отдельно на любом этапе. Неверные ответы не сбрасывают находки.

После совпадения даты сразу появляется конверт для вскрытия жестом. Личное письмо хранится только на сервере и появляется в API после открытия. Анимация распаковки и розовое оформление финала сохраняются. Письмо можно перечитать, вернувшись в дело с главной страницы. Дополнительной загадки на имя нет.

У каждого этапа три уровня подсказок. Последний требует явного подтверждения; подсказка по фильму позволяет продолжить без просмотра. Обязательные действия, проверки и подсказки не зависят от доступности Groq. Свободный разговор использует открытые материалы и найденные сведения; до решения года или прямой подсказки модель не получает готовую расшифровку. Полная дата и личное письмо не передаются модели заранее.

Существующие записи, блокнот и история переписки сохраняются. Состояние хранится на сервере, выбранный документ — в браузере, блокнот — локально. Старое выбранное значение календарей заменяется доступным документом. Сброс дела не обнуляет лимит обращений к Groq.

## Где менять

- `public/data/book-cipher.json` — общий источник точных строк записки и пар для книжного шифра.
- `src/content.js` — публичные документы, карточки и фильм с таймкодом.
- `src/styles.css` — ночной город, типографика, карточки, адаптация к телефону.
- `src/app.js` — экраны, модальные окна, переписка и формы.
- `backend/quest/story.py` — приватная проверка ответов и ограничения персонажа.
- `backend/quest/views.py` — серверные переходы и обращения к Groq.
- `backend/.env` — ваш ключ и параметры сервера; файл исключён из Git.

## Размещение

```sh
npm run check
npm run build
```

`dist/` содержит только статическое оформление. Для работающего чата, сохранения и проверки ответов нужен Django. Для Vercel готова [отдельная инструкция](backend/deploy/VERCEL.md), конфигурация и подключение PostgreSQL через `DATABASE_URL`. На своём сервере используйте Gunicorn + Nginx; примеры и настройка HTTPS — в `backend/README.md` и `backend/deploy/`.

Шрифт и происхождение фонового изображения описаны в [ASSETS.md](ASSETS.md).

Новая миграция: `0005_investigation_year_solved`. Она добавляет сохранение найденного года, не удаляя прежние данные. Команда `npm run dev` применяет миграции автоматически перед запуском. Для ручного запуска сначала выполните `backend/.venv/bin/python backend/manage.py migrate`.

## Проверки

```sh
npm run check
node --test scripts/game.test.mjs
backend/.venv/bin/python backend/manage.py test quest
npm run build
```

Проверки охватывают акростих, чтение координат по настоящим строкам, независимую проверку года и даты, сохранение сессий, обработку ошибок и защиту закрытых сведений. Интерфейс и полную цепочку дополнительно проверяют в браузере на компьютере и телефоне.
